# Notes for coding agents

This is Gabriel's personal academic website (Jekyll, Academic Pages theme,
"dirt" theme with neutral cool grays). See `README.md` for the file map.
Do not open pull requests against the upstream template.

## Design conventions

- **Cards**: Projects, Events and Publications are cards (`.project-card`).
  Hierarchy is title, then a gray italic line, then description, then link
  boxes. No bullets inside cards, except the CV's bullet lists.
- **Hidden titles**: pages with `hide_title: true` keep an `<h1 class="sr-only">`.
  Do not remove the heading from the HTML.
- **Links as boxes**: use `.tl-link-btn` with a meaningful name (`paper`, `code`,
  `page`, `grant`, `event website`, `group website`, `transcript`). Never "link".
  Order on Projects: page, code, paper. External links open in a new tab with
  `rel="noopener noreferrer"`.
- **Bold**: avoid it. Titles of cards and headings are the only bold text, plus
  the labels in the CV's Skills and Languages.
- **Quotes**: names of papers, theses, projects and study groups go between
  curly quotes when they appear inside a sentence. Not in card titles.
- **Dates**: `Mon YYYY` (e.g. `Sep 2025`); ranges as `Mon YYYY – Mon YYYY`.
- **Names**: write "Universidade de São Paulo (USP)" and "Gabriel da Costa Merlin".
- **Colors**: neutral cool grays plus one muted blue for links. Light text
  `#313438` on `#f3f4f5`; dark text `#d9dbdd` on `#1e2124`. Keep gray text
  readable (at least 4.5:1). Palettes live in `_sass/theme/`; do not hardcode
  colors in pages. Dark mode follows the system setting and has a toggle button.
- **First author**: Publications cards where Gabriel is the first author get
  the highlighted background; the legend explains it.

## Content files

- Updates timeline: `_data/updates.yml` (`date: "Mon YYYY"`, `type: paper|grant|thesis|event`).
  The "Last 12 months" filter reads the date, so keep that exact format.
- Events: `_data/events.yml`. Projects: `_projects/*.md` (`logo`, `logo_bg`, `links`).
  Publications: `_publications/*.md` (`authors`, `venue`, `venue_full`, `link`, `link_label`, `code`, `page`).

## Pitfalls

- `_config.yml` changes need a restart of `jekyll serve`.
- `blank` is a reserved word in Liquid; do not use it as a variable name.
- The theme's HTML compression strips spaces between inline links; space them with CSS.
- Safari decides the color of the overscroll area itself; it only updates on page load.
- `assets/js/main.min.js` is generated by the workflow and by `npx uglify-js ...` locally.
- The downloadable `files/cv.pdf` is Gabriel's own document, not generated from the site.
